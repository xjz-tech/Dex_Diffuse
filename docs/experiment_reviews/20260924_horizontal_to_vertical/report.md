## 初始化的近似与筛选

真实数据没有物体 6D 位姿；转换目录中的 `obj_state.npy` 全零，不能用于初始化。没有把机械臂 TCP 数据冒充灯泡位姿。

首帧采用真实测量的 22 个关节角（policy/Isaac 顺序，弧度），原生关节极限裁剪，速度置零。仿真手腕工程近似设为手指朝下：xyz=(0,0,0.6)m，xyzw=(1,0,0,0)。整段固定手腕，不重放缺少 TCP→仿真手腕标定的机械臂运动。源片段 TCP 实际变化约 12.02°、4.27 cm，因此不是完整真机轨迹复现。

以首帧关节近邻的 3 条原生示范物体相对手腕位姿为基点，先试 21 个 ±5 mm 候选，全部静态失败。第二轮用 144 个候选：x 偏移 0/20/40/60 mm，y 偏移 0/20/40/60 mm，z 偏移 −20/0/20 mm。仅保持首帧手势 2 s，按位移、关节误差、接触诊断、水平程度和原生 failure 选位置，没有执行转正 reference 来选点。

第二轮 71/144 未触发静态 failure。最终选择 demo132/frame294，局部偏移(+40,+20,0)mm；静态位移 20.78 mm，末态离水平 0.86°，两指接触诊断。所选相对位姿详见 [fit2/placement.json](fit2/placement.json)。各候选的原生物理参数有随机差异，筛选分数并非纯位置因果比较。

正式实验将同一个选中摆放放入新的 3 个原生随机物理实例，均通过 2 s 静态阶段。静态结束时分别距竖直 86.28°、103.85°、105.35°。引导组与直接组的 27 项初始字段，以及完整 60 步静态轨迹逐元素一致。没有按动态成功结果重选摆放。

## 控制与原生协议

使用 `/home/carus/data_usb/10B_obs_4-66.ckpt` EMA，66 维观察、22 维动作、horizon12；Prior DDIM4，每次执行2步，reference 引导前2个可执行动作，scale25，固定噪声 seeds42/43/44。直接用数据中的绝对关节目标作为数值 reference，没有独立学习式 guide 网络，因此没有 guide DDIM 参数。直接回放对照不经过 prior，也不是 guided scale0。

环境 seed42 的三个物理实例，不是三个独立环境 seed 的统计实验。保留原生物理随机化、外力、目标更新、误差坐标系和失败累积逻辑，示范范围000–149；显式配置位置0.05m、指尖0.1m、旋转180°、立即失效位置0.15m、FailureToleranceScale10000、fixedToleranceSteps20000、resetOnReachGoal=false、跨轨迹目标概率0.3、trajStepsLimit12000。失败位置误差仍是相对于当前示范目标的物体相对手腕位置误差。

30Hz，每帧执行一步，不插值、不额外限幅；推理等待期间物理不前进。2s静态+3s reference+1s末目标保持。首次failure锁存，之后继续录像的姿态只作诊断，不统计为成功。本实验改变了初始化、固定手腕姿态和外部reference，并采用短动作观察窗口，不与常规400s保持实验的绝对时长混比。

完整90步内，guided输出命令相对reference的RMSE为0.158–0.179rad，直接回放命令误差为0；实测关节相对真实测量轨迹的RMSE分别为0.161–0.174rad与0.064–0.077rad。这些误差包含failure后的诊断帧，不是成功操作阶段专属指标。
