## 对照定义

参考是真实数据 episode37 的 action160–249，共 90 个 22 维手关节目标；每步 1/30 秒。直接组的 case110 命令逐项等于 `reference.npz` 中 `hand_target_rad`，经原生限幅/绝对位置控制接口执行，不使用 prior 的输出。引导组为 `10B_obs_4-66.ckpt` EMA、DDIM4、每次执行2步、引导前2步、scale25、固定噪声 seed44。这里的引导来自记录的关节目标，不是另一张 learned guide checkpoint，因此没有单独 guide DDIM。

两组均采用原生 wrist，灯泡质量 0.17 kg，手和灯泡滑动摩擦系数 2.2，其余物理随机化保留原生值。2 秒静态抓持、3 秒动作、1 秒末态保持。保留原来的 189 环境初始化上下文，其余 188 个环境仍执行引导动作，仅比较 case110；189 不是本次对比样本数。直接组服务端仍按原微批次计算 case110 的候选输出，但仿真端丢弃它，执行原始目标。

两组 27 项初始状态逐项完全相等，并与首次 sweep_final 存档完全相等。case110 前 60 步静态阶段所有已记录状态逐项完全相等，包括 q、qd、物体位姿和速度、wrist、命令、接触力、目标索引及 failure；全 180 步施加的随机外力也完全相等。其他环境的动态轨迹存在差异，不将其结果混入 case110 对照。

沿用原生 `xjz_test.sh` 评估逻辑：示范000–149，物体位置误差0.05 m、五指尖误差各0.1 m、旋转误差180°、立即失效位置误差0.15 m、FailureToleranceScale10000、fixedToleranceSteps20000、resetOnReachGoal=false、crossTrajectoryGoalProb0.3、trajStepsLimit12000。位置误差仍为当前物体相对 wrist 与当前原生示范目标之差。没有另设物理掉落阈值或修改 RL 默认值。

原生 failure 与物理脱手分别判断：直接组在 1.633 秒触发原生 failure，实际渲染也显示灯泡离开手部并落到下方桌面；failure 后保留画面和数值仅用于诊断，不计为继续成功。引导组在动作结束和保持结束画面中仍持有灯泡。接触力统计是指尖净接触力，不能独立证明手—灯泡接触。

这是一例对照，不是成功率估计。数据缺少可用灯泡6D位姿，因此采用先前拟合的近似物体初态；仅回放手指参考，不回放未标定的真实机械臂/TCP运动。本次结果支持 prior + 引导改善该仿真初态下的抓持和转向，不能据此断言所有初态均可成功。

## 产物与复查

`direct/`、`guided/` 各自保留初始状态、完整轨迹、配置、两视角原始视频和日志。`protocol.json` 记录实验变量；`source/` 与 `source_hashes.json` 保存任务和控制器源码快照；`verification.json` 记录初态、静态前缀、外力和视频帧数验证。NOKOV 数据预处理缓存核验 RNG 状态，仅缓存原生数据预处理，物理环境每组重新创建。

入口为 `run.py direct` / `run.py guided`，分析入口为 `analyze_pair.py`；启动器分别使用 dp 与 decv2 环境。不要覆盖当前存档进行复跑，请复制实验脚本到独立输出位置并相应保持 reference、fit2 路径。
