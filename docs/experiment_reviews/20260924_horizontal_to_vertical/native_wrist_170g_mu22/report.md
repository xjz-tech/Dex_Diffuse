# 原生 wrist，170 g / 摩擦2.2：邻近灯泡初态扫描

这次出现了能把横向灯泡明显转起并保持的近成功案例，但尚未得到稳定、完整转正。最接近的 **case110** 两次均从约80°的横向初态转向竖直，最终分别距竖直23.63°、29.88°，执行3s轨迹及随后1s保持期间均无原生failure。两次灯泡轴相对手腕分别改变97.65°、95.31°；这是轴方向变化，不是绕灯泡自身轴的自转角。

上轮手部外观异常的原因是人为把wrist旋转成“手指朝下”，且相机从遮挡方向拍摄。本轮撤销该设定，**每个环境保留自己的原生wrist位姿**，不复制或指定新的手腕姿态。改用原生场景前方及较低侧面的双视角，单案例大画面，不将多个案例挤在一个小面板里。

## 参数与检查

- 灯泡质量0.170 kg，即170 g。更新刚体质量并重算惯量，同时同步任务中的物体质量缓存。
- 手和灯泡全部碰撞面的滑动摩擦都设置为2.2。逐环境读取实际属性核实质量及两侧摩擦。滚动／扭转摩擦、恢复系数、物体尺度、手部质量与增益、外力等其余参数保留原生随机化。
- 初始手指采用真机id37/frame160的测量关节角，reference是frame160–249的90个绝对关节目标。未替换成其他模型的动作。
- 10B EMA prior，DDIM4，执行2步，数值reference引导前2步，scale25。固定噪声42/43/44重复用于每组位姿；模型请求按9个实例微批处理，等待推理时物理暂停。没有独立学习式guide网络，因此没有guide DDIM采样。
- wrist与各环境原生初始化的位姿逐元素核对；运行中继续检查实际wrist未改变。所有189个实例的实际物体质量为0.17kg，实际手／物体摩擦为2.20000005（浮点表示）。

## case110 的初态与动作

灯泡相对手腕的位置约为 `(0.03091, -0.12095, 0.13996)` m，四元数xyzw为 `(0.08808, -0.84712, 0.26651, -0.45122)`。它来自第二个中心摆放，沿手腕Z轴再加1cm，绕手腕X轴−15°。noise44，手腕采用原生第110个环境的初始化。

## 重复试验与限制

两轮27项完整初始字段逐元素一致，全部wrist轨迹也一致，但接触运动并非逐帧一致；case145、153、154的静态／最终failure分类改变。原因未在本任务中单独定位，不能声称逐帧确定性复现。第二轮是为首轮7个静态通过案例补录清晰视频而重跑，不能与首轮合并计算独立成功率。case110两轮都表现出接近转正并抓持的趋势，但末态角度不同，仍需进一步提高稳定性。

真实数据缺少灯泡6D位姿，本轮初态仍是近似摆放。原生wrist与上一轮人为朝下wrist的重力方向不同；本轮同时记录世界朝向和相对手腕的轴方向变化，不把更换坐标系带来的朝向差当作完成动作。

严格完成标准在运行前记录：静态结束时距竖直60–120°，全程无原生failure，末段保持最后0.5s持续处于20°内，并核验抓持。该指标只用于“动作完成”，没有替换原生failure。

## 评估协议与归档
