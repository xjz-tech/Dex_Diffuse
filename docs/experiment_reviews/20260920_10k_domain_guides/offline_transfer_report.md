# 留出专家观察的动作预测误差

每个物理域使用相同4个留出模板，各选10个观察窗口。所有模型使用相同DDIM4噪声，比较接下来执行的两个目标动作与专家动作的平均绝对差，单位rad。五个新模型训练时均没有使用这4个模板。

| guide | 轻／低测试域 | 轻／高测试域 | 重／低测试域 | 重／高测试域 |
|---|---:|---:|---:|---:|
| old10k | 0.05197 | 0.04942 | 0.05225 | 0.05090 |
| light_low | 0.04547 | 0.04281 | 0.04473 | 0.04544 |
| light_high | 0.04261 | 0.04129 | 0.04532 | 0.04455 |
| heavy_low | 0.04426 | 0.04249 | 0.04547 | 0.04441 |
| heavy_high | 0.04533 | 0.04184 | 0.04517 | 0.04496 |
| balanced | 0.04385 | 0.04212 | 0.04476 | 0.04468 |

这是专家观察条件下的开环预测，不是保持成功率。模型实际闭环访问的状态、guide与1B的结合效果，以及失稳后的恢复能力都未由这项误差衡量。不能用这张表替代仿真排名。

留出指未参与梯度更新；归一化沿用项目现有get_normalizer实现，统计整个replay buffer（含验证片段），不是严格仅训练集拟合的归一化。
