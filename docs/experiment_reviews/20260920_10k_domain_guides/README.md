# 五种带物理标签的10k guide对照

[完成报告](/home/carus/Program/Dexterous_Manipulation/Dex_diffuse/docs/experiment_reviews/20260920_10k_domain_guides/final_report.md) · [模型/数据分布登记](/home/carus/Program/Dexterous_Manipulation/Dex_diffuse/docs/experiment_reviews/20260920_10k_domain_guides/guide_registry.md)

固定1B，不训练1B。四个受控采集域：40–80g/180–300g × 物体摩擦0.5–1.5/2.5–4.0；第五组四域均衡混合。实际采样范围与逐轨迹质量、物体/手部摩擦、惯量、Kp/Kd见physical_slots.json、datasets.json及每个数据集distribution_manifest.json。guide_registry.json永久联接数据分布和模型路径。

每个数据集40个连续250步片段，共10000步，其中36片段9000步用于训练，4片段1000步验证。四域使用配对手部参数和初态模板，仅纳入四域均有在含4步预热的254步尝试中至少2次原生目标到达且未原生失败的共同模板。混合组训练中每域2250步、验证中每域250步。它们不是未经筛选的均匀DR样本，也不是40个完整终止episode。原始尝试/保留统计见collection_attempts.json。

原SAPG专家SHA256与2026-08-27源数据一致；专家采集沿用源任务原生阈值。DP评估使用xjz_test阈值，二者不混淆。物体尺寸固定1、质量改变后重算惯量并同步实际质量缓存；未修改RL默认参数。

训练从头开始，五组同seed42、同200epoch、相同网络/EMA/优化器/批量。原10k作为历史参照，其片段构成与新数据不同，不能把新旧差异全部归因于物理分布。首轮只使用一个训练seed，属于探索性对照。

评估：四初态（demo079、082、094、真机pose50）×四物理组合（44/240g × μ1.312/2.572）×三个策略噪声seed（8、19、25），每方法48次。比较普通1B、旧10k和五个新guide，共336次。DDIM4/4、执行2步、scale25引导前2步，400秒观察上限；150示范与原生目标切换/失败逻辑保持。原生pre_physics_step使用单独且相同的CUDA RNG流，使各方法的本地外力抽样配对；原生概率、衰减、施加方式不变。未失败环境不因其他环境失败而reset。实际录像覆盖三个噪声seed的代表案例。

当前：全部完成。五个新模型均已完成200epoch/3600次更新；7种方法共336例闭环评估完成，21个单独视频、3组原速并排视频、3组10倍速预览均已校验。checkpoint、数据哈希和配对参数检查通过。第一次普通1B评估在用户中断时停止于240秒，部分记录保存在interrupted_attempts，不计入完整结果；已从头重跑。评估最多并行两个方法，各有独立环境和模型进程；全部已结束。

模型输入均为22维关节角、22维上一目标和22维目标残差，共66维；不直接输入质量或摩擦标签。物理标签用于追溯训练分布和分层分析，不能理解为模型显式知道测试物体的质量／摩擦。各模型验证集来自自己的数据分布，因此验证loss不用于跨分布排名。

补充数据审计：旧10k的8910训练帧中，有18帧目标残差RMS低于0.001rad（对应18个训练片段起点）；五个新训练集各9000帧中均为0。新采集跳过4步预热，而DP评估初始化把目标设为当前关节角、残差为0。此起始观察覆盖差异是解释新旧早期失败差异的候选因素，尚未做消融证明，不能直接归因于质量／摩擦。见initial_residual_coverage.json。

留出指未参与梯度更新；归一化沿用项目现有get_normalizer实现，统计整个replay buffer（含验证片段），不是严格仅训练集拟合的归一化。

四域混合组平均129.90秒、≥20s为60.4%，优于本轮四个新单域guide；普通1B为80.05秒/54.2%，旧10k为167.59秒/54.2%。混合组共享新数据无零残差起点的限制，却改善了早期表现，因此该覆盖差异不能单独解释性能。所有结论限本轮诊断初态和固定scale25。
