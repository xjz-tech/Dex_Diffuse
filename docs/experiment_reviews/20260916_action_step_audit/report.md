# 仿真训练数据单步动作幅度审计

统计相邻控制步的绝对变化，排除episode边界。目标角变化与实际关节角变化分别计算。来源是RL仿真训练轨迹，不是昨天10k guide→1B评估运行的逐步输出；该评估未保存足够的逐步关节数据，不能回溯其精确分布。

| 指标 | 10k guide训练集（9979个有效步） | 全量源数据抽样（130878个有效步） |
|---|---:|---:|
| 单关节目标变化平均绝对值 | 0.029292 rad | 0.029412 rad |
| 单关节目标变化中位数 | 0.012275 rad | 0.012445 rad |
| 单关节目标变化P90/P95/P99 | 约0.09 rad | 约0.09 rad |
| 目标变化超过0.03的关节更新比例 | 37.22% | 37.44% |
| 至少一个关节目标变化超过0.03的控制步比例 | 92.25% | 93.08% |

10k数据中实测关节角变化均值0.022577 rad，P95=0.081531 rad。真实脚本限制的是相邻发送目标变化，应与目标变化分布比较。

当前真机入口默认MAX_HAND_STEP=0.03 rad且默认启用；用户本次实际启动参数未提供。相对于上述训练目标序列，该门槛会改变相当多的更新；比例不是实机实际截断率，也不能证明回拉由此导致。执行后目标和反馈会改变闭环状态，不能把训练轨迹逐步阈值超限统计当作闭环限幅仿真的结果。

建议先对同一guided policy记录原始目标、发送目标与实测角度，并在仿真中单独加入0.03 rad限幅作对照。不要直接把0.09 rad作为已验证的真机参数。此前3000环境WAIT比较没有加入该真机单步限幅，不能排除此差异。

复核：analyze.py、statistics.json。全量源数据采用seed42随机256个连续窗口，每窗512次更新，排除跨episode变化。
