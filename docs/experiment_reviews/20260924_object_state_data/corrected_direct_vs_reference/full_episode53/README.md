# Episode 53: frame 90 to data end

The previously tested reorientation segment used recorded hand actions 90–164. This continuation uses every remaining recorded hand action through 446, with recorded state 447 as the endpoint. It compares three fresh rollouts from the same imported initial state: direct recorded joint targets, and 10B prior guided by one-target interpolation with guide horizon 2, scale 50, executing either 2 or 1 action per call. Every pair of adjacent recorded targets receives one linear midpoint; both guided runs therefore execute 713 targets, while direct executes 357. Each rollout then holds its final target for 60 physics steps.

All three first import snapshots have 27 matching numeric fields exactly, and their 60-step settling trajectories match exactly. The new reference reproduces the old episode-53 reference for its first 75 actions and 76 states. Runs use the native `eval/xjz_test.sh` protocol and native failure logic via `compare_corrected_rollouts.py`; 000–149 demo, 170 g, friction 2.2, DDIM 4, seed 44 fixed noise, original native wrist, and the corrected property-flush/import order are unchanged. Native failure is the evaluator's failure proxy, and the video shows the bulb no longer held near the end.

The real recorded wrist travels 17.74 cm and rotates 23.5° between frames 90 and 447 (maximum displacement from frame 90 is 20.42 cm); the simulated wrist is fixed. The real episode proceeds toward the socket and releases the bulb there, whereas the simulated hand remains in place. Consequently this full-episode rollout tests whether finger-only control can retain the bulb under the recorded hand targets. It cannot establish whether the complete real placement task would succeed with wrist replay.
