# 每个记录动作复制成 8 个 guidance 点：两种时间映射

同一 episode53 源第90帧、原生 wrist、170g、手与物体摩擦2.2、10B EMA、DDIM4、scale25、模型噪声 seed44。两组对照都在变更质量/摩擦后先推进并同步 PhysX 一帧，再导入完全相同的手/物体初态。所有新组与原 guide2/guide9 的 27 项初态字段、前60步静置轨迹逐项相等。每次 inference 只执行生成的前2步。原生 failure 阈值与目标流未更改。

“每一个 reference action 当成 8 个 reference actions”有两种执行时长含义，分别实跑并单独录像：

1. **当前目标复制8份，执行2步后换下一个原始目标。** 每次 guide 窗口是 `[a_i] × 8`，共75次推理、150个动作控制步（5秒）和2秒保持。直接组对照在同样150步内把每个原始目标执行2次。[7秒视频](tile8_advance_per_call/episode53_tile8_direct_vs_guide8_7s.mp4) · [动作结束静帧](tile8_advance_per_call/tile8_action_end.png)。引导组动作末灯泡距竖直56.6°，相对导入位移2.76cm，记录末态 wrist 系轴误差39.1°；直接组为17.8°、7.91cm、28.0°。两组至2秒保持结束均无原生 failure。引导输出相对重复后的记录目标 RMSE 0.161rad。
2. **把整条记录轨迹放慢8倍。** 每个原始目标真实执行8个控制步，拼成600步（20秒）；每次从这条展开轨迹取接下来8点 guide，执行2步后重新推理。这个窗口在接近8步边界时会同时包含当前和下一个目标。[22秒视频](repeat8_guide8/episode53_repeat8_direct_vs_guide8_22s.mp4) · [18秒静帧](repeat8_guide8/repeat8_eighteen_seconds.png)。直接组于动作步500（16.7秒）触发原生 failure；引导组在动作步570（19.0秒）仍从两个视角可见灯泡在手中，距竖直27.7°，但随后脱手，于动作步590（19.7秒）触发原生 failure。故接近竖直只是短暂阶段，整段没有成功保持至结束。

两组视频都以实际仿真30fps播放。真机源帧按相应倍数重复显示，以便对齐记录动作索引；额外2秒的真实图像固定在第165帧，仿真继续保持最后下发的关节目标。这不代表真机实际被放慢或暂停。两种时间映射改变了动作持续时间，不能只拿末态角度直接比较“8步 guidance”的优劣。

注意共用的60步静置已使灯泡相对导入位姿平移3.14cm、转动27.9°；真实TCP运动没有在仿真中回放，网格与外参也未独立标定。原生 failure 和可见脱手分开判断，尤其展开8倍的引导组在原生 failure 前数帧画面已明显分离。完整数值及逐项配对核验见[指标JSON](repeated_reference_comparison.json)；各运行的 `trace.json`、`summary.json`、`initial_state.npz` 和完整视频保存在相应目录。
