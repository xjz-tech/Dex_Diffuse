# Episode 53：修正初态后的直接执行与 reference 引导

用户提出“每个记录动作复制成8个guide点”的两种可执行时间映射已分别实跑：每次推理复制当前目标并执行2步后换下一个，及整条记录轨迹放慢8倍。对应视频、结论和区别见[重复参考实验](REPEATED_REFERENCE.md)。

## guide9、执行前4步

[真机／直接执行／guide9-exec2／guide9-exec4 的4.5秒视频](episode53_direct_guide9_exec2_exec4_4p5s.mp4)；[动作结束静帧](execution_steps_action_end.png)。使用原始75个记录动作、reference不重复、DDIM4、guide9、scale25、模型噪声seed44。exec4 每次从当前动作索引取未来9个参考目标引导10B，执行生成的前4步后才重新推理；最后从动作索引72开始的一轮只执行剩余3步。两组27项初态及前60步静置轨迹完全相等。

| episode53 动作结束 | guide9 / exec2 | guide9 / exec4 |
|---|---:|---:|
| 距世界竖直 | 79.0° | 98.0° |
| 相对导入位置偏移 | 2.06cm | 2.25cm |
| 灯泡轴相对真机末态的wrist系误差 | 62.5° | 78.7° |
| 执行动作相对记录reference的RMSE | 0.168rad | 0.191rad |

本例执行4步后转动较少，保持额外2秒时约99.0°，没有追上真实末态。改变每次执行步数也改变了闭环反馈频率：exec2 共38次模型调用，exec4 共19次；不能只按reference长度推断引导强弱。[数值与配对核验](guide9_exec2_vs_exec4.json)。

[真机／直接执行／guide2／guide9 的 4.5 秒四宫格视频](episode53_direct_guide2_guide9_4p5s.mp4)；可直接打开的[动作结束静帧](guide_horizon_action_end.png)和[再过两秒静帧](guide_horizon_plus_two_seconds.png)。guide9 和原 guide2 使用相同的初态、原生 wrist、灯泡质量/摩擦、10B 权重、DDIM4、scale25、模型噪声 seed44、每次执行2步。两组只有每次用于引导的未来 reference 长度不同。27项初态完全相等，前60步静置轨迹逐项相等。guide9 的最后四次推理（从动作步68、70、72、74起）缺少未来参考时，将最后一个记录目标重复填充到9步；第74步只执行这一轮的第1步。

guide9 在这个个例里比 guide2 更接近记录关节动作，灯泡也多转了一些，但仍未达到真机末态的方向；额外保持2秒后距竖直约77.9°。损失函数对所有 `guidance_steps × 22` 元素取均值，因此固定scale25时，9步与2步的逐元素梯度权重不同；本对照回答“直接把引导窗口延长到9步”的实际效果，不是保持每一参考点梯度强度不变的消融。详见[指标及配对校验](guide_horizon_comparison.json)。

[四宫格 4.5 秒视频](episode53_real_direct_reference_4p5s.mp4)：上排是数据集真实前视角和腕部视角；下排左是真机记录的 22 维手关节目标在仿真中直接执行，右是 10B prior + 该动作轨迹的 reference 引导。前 75 帧（2.5 秒）按名义 30 Hz 对齐真实源帧 91–165；后 60 帧（2 秒）真实视频继续播放源帧 166–225，仿真保持各自最后的关节目标。这 2 秒是保持观察，不是继续对齐真实动作控制。可直接打开的静帧：[动作结束](episode53_action_end.png)、[再过 2 秒](episode53_plus_two_seconds.png)。

这是 **episode 53、源第 90 帧、无额外物体姿态扰动** 的一次成对实验。两次独立仿真均固定随机种子 42；所有 27 项导入初态字段完全相等，导入后保持首帧目标的 60 步静置轨迹逐项相等。设置灯泡质量与摩擦后，先推进并同步一次 PhysX，再写入手和灯泡初态，避免旧实验中的根位姿写入失效。灯泡 170 g，手和灯泡滑动摩擦 2.2；原生 wrist 固定，原生目标流与 failure 参数不变。直接组的执行命令逐项等于记录动作；引导组用 10B EMA，DDIM 4、执行 2 步、引导前 2 步、scale 25。

| 指标 | 直接执行记录动作 | 10B prior + reference |
|---|---:|---:|
| 动作结束距世界竖直 | 21.5° | 115.8° |
| 动作结束灯泡相对导入位置偏移 | 8.05 cm | 2.29 cm |
| 动作结束灯泡轴相对真实末态的 wrist 系误差 | 20.7° | 92.8° |
| 动作阶段灯泡轴相对 wrist 的转角 | 100.1° | 10.2° |
| 再保持 2 秒后距世界竖直 | 18.8° | 115.7° |
| 全程原生 failure | 无 | 无 |

真实记录片段中灯泡轴相对 wrist 转过约 68.0°。直接执行在这一例里产生了接近真实末态方向的转动，但转角过大且灯泡中心相对导入位置移动约 8 cm；引导输出更接近保持原抓握，没有完成转正。引导输出与记录关节目标的 RMSE 为 0.227 rad。两组均未触发原生 failure，但这不等于确认真实抓握复现。

进入动作前的共同静置阶段已经使灯泡相对导入位姿平移 **3.14 cm**、旋转 **27.90°**；真实 TCP 在动作期间会移动，仿真 wrist 则保持原生固定位置。灯泡外覆层尺寸及 TCP→手根、动捕→网格外参仍未标定，所以本结果只说明这两个控制策略在**相同修正后仿真初态**下的差异，不应称为物理上可信的真机转移成功率。
