预设顺序：

1. DDIM4、exec2，训练扩散时刻t6～t10的五个噪声强度。t8、seed44结果复用同配置既有存档，其他四组新跑。
2. 按稳定翻转个数优先、四条原始进度均值其次，固定顺序选第一阶段最好的两组；分别测试exec1、exec3、exec4（DDIM4）。
3. 在前两阶段的全部组合中按同一规则选前两组，原噪声时刻和exec不变，测试DDIM6。DDIM时刻从各噪声起点局部选取。任何结果均保留，不根据单条episode输赢挑选。
