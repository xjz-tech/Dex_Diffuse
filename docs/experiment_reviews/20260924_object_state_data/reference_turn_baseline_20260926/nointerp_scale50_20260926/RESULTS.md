# Scale 50、guide 2：未插值 reference 的翻转对照

使用相同四个原始 direct 已通过翻转验收的横抓起点：episode 76/f114、34/f79、54/f110、2/f103。新跑 8 次完整 guided 回放：原始 30 Hz reference 不插值，10B EMA、DDIM4、guide horizon 2、scale 50，分别执行每次生成的前 1 或 2 步。170 g、摩擦 2.2、固定 wrist、环境 seed 42、prior 固定噪声 44、60 步静置、完整动作尾段和额外 60 步保持均沿用上轮设置；未录新视频。原生环境 failure 协议未改。

首次连续 3 控制步满足独立几何/接触分离判据时的**原始 reference 动作进度**如下，越晚越好。未插值每执行 1 步就前进 1 个原始动作；插值列沿用先前实验，用原始动作进度对齐（`.5` 为中点）。括号内表示是否通过“翻竖后在空中连续握住至少 30 控制步”的稳定翻转验收。

**结论：未插值时 scale 50 仍能翻转，但这四条中只有 2/4 通过；不能笼统说它完全翻不过来。** episode 54 的两种执行步数均在 reference 进度 57 脱手，未达到连续 30 步竖直接触；episode 2 的 exec2 保持到 266，超过原始 direct 的 195，也超过插值 guided 的 216。翻转结果对 episode 与执行步数都敏感。就当前四条而言，插值 guided 两种执行步数均为 4/4 通过，但它把物理执行时间约加倍，所以要同时看原始动作进度和实际控制时长，不能用裸控制步计数比较。

新增 8 次结果逐项验证：同 case 的初态文件所有字段与原始 direct 完全一致；60 步静置记录除物体净接触力浮点归约差异外逐字段一致，力差小于 `1e-5 N`；预测窗口从 reference 索引 0 开始并按实际 exec1/2 前进；完整动作尾段与 60 步 hold 均已运行，未按物理分离或 native failure 提前停止。原生 failure 仍单独保存，不能等同物理脱手。几何分离阈值改为 3、8 或 10 mm，新增组进度最多变化 1 个动作。

结果仅限这四个按原始 direct 成功条件筛出的起点、固定环境 seed 和 prior 噪声。新增组未作录像独立确认；物理保持来自手/物碰撞网格距离与接触力分析。固定 wrist 的测试不代表完整真机放置成功率。
