# 170g/2.2 与 44g/1.1：scale25/50 翻转差异诊断

2026-09-27。用户确认比较的是170g与44g，不是140g。

已经通过存档逐步分析、同条件复现、质量×摩擦单因素对照和固定cmd交换回放，定位到**物理条件与引导生成手型的交互**。不能把结果统一解释成“scale25推理慢/整体跟不上”，也不能简单归因“摩擦大所以卡住”或“轻物体总是更容易”。精确到哪个接触点的切向力矩导致差异，目前证据仍不足。

## 对齐实际实验版本

用于可比分析的是相同四个起点76/f114、34/f79、54/f110、2/f103，10B EMA（`/home/carus/data_usb/10B_obs_4-66.ckpt`）、guide2/exec1、30Hz、相邻22关节最大跳变严格>0.12rad插一个中点、完整reference尾段、60步静置与60步末目标保持、环境seed42、固定prior噪声44。这里guide是记录的关节目标，没有另一张learned guide网络/独立guide DDIM。DDIM4与16分别分析，未混用exec2或全插值旧实验。

| 存档配置 | 170g/2.2稳定翻转 | 44g/1.1稳定翻转 |
|---|---:|---:|
| DDIM4 / scale25 | 3/4 | 4/4 |
| DDIM4 / scale50 | 4/4 | 3/4 |
| DDIM16 / scale25 | 3/4 | 3/4 |
| DDIM16 / scale50 | 4/4 | 2/4 |

因此本组存档不是“0/4→4/4”。另外44g的>0.10插值scale25版本为3/4，不能混作>0.12版本的4/4。四条都是先以原始direct可完成翻转为条件选定的子集，不能解释成随机总体成功率。

## 最关键的新实验：episode54完整2×2物理对照

episode54是DDIM4中scale25/50优劣互换的失败条目。固定其原始初态、reference、时间表和所有其他参数，补齐170g/1.1与44g/2.2，每个条件先验收未经修改的原速reference。新条件direct分别有37和39个连续竖直接触控制步，通过数值验收；另补录实际运行视频并复核横转竖、悬空接触及录像/无录像全程逐值一致。

下表数字是**首次持续几何/接触分离前，连续近竖直且仍悬空接触的最长实际控制步数**。沿用既有≥30步验收，不是native failure步数，也不是总保持时间。

| 质量 | 摩擦 | scale25 | scale50 |
|---|---:|---:|---:|
| 170g | 2.2 | 11，未通过 | 51，通过 |
| 170g | 1.1 | 4，未通过 | 36，通过 |
| 44g | 2.2 | 7，未通过 | 0，未通过 |
| 44g | 1.1 | 42，通过 | 8，未通过 |

这里可以作出局部因果判断：

- scale25从170g/2.2出发，单独减小质量或单独减小摩擦都没有救回稳定翻转；两者同时改变才通过。不能把成功单独归于轻质量或低摩擦。
- scale50在两种170g条件都通过，在两种44g条件都失败。降低摩擦本身没有救回44g/scale50。
- 降低质量并不普遍改善翻转；增大scale也不普遍改善翻转。这是固定episode、固定seed下的交互证据，未扩展到所有episode或种子。

完整新增结果见[因子对照结果](factorial_results.json)，各运行目录的`commands.json`保存实际模拟器/策略服务命令，`trace.json`保存每步cmd、实际目标、q、物体位姿及接触，`diagnostic_result.json`保存验收结果。其中历史字段`baseline_qualified`在guided行表示同一稳定翻转数值判据是否通过，不表示重新筛选了起点。

## cmd检查：scale50更贴reference，但44g翻转更差

在相同前60个实际控制步内，四组都尚未发生首次持续分离：

| episode54条件 | cmd-reference RMSE(rad) | q-实际目标 RMSE(rad) | 第60步距竖直 |
|---|---:|---:|---:|
| 170g/2.2，scale25 | 0.08311 | 0.06491 | 43.7° |
| 170g/2.2，scale50 | 0.04189 | 0.05818 | 25.1° |
| 44g/1.1，scale25 | 0.08161 | 0.06676 | 43.6° |
| 44g/1.1，scale50 | 0.04138 | 0.06665 | 66.2° |

scale50确实约减半了生成动作对reference的误差，但44g的实测关节执行误差与scale25几乎相同，物体旋转却明显更差。第90步44g/scale25距竖直29.5°，scale50为50.0°；这不是比较脱手后的关节误差。

前120步cmd与实际送入的关节目标仅有约1e-7rad级浮点差，没有发现限位裁剪造成这种反转。控制步11–120内，将reference前后平移±10步检查，四组cmd的最低RMSE都位于零平移：不支持“整个cmd晚了若干控制步”这个简单模型；这并不排除某个关节局部动态滞后。策略推理期间模拟器等待，墙钟推理耗时不会直接把30Hz物理轨迹快进。

误差有明确的手型方向，而非单纯延迟。例如44g前60步，scale25的无名指MCP_FE相对reference平均+0.187rad，小指DIP为−0.148rad；scale50分别约+0.086rad和−0.061rad。增大scale会改变指间配合和接触构型；它不是把电机力或PD刚度乘二。具体哪个关节的偏差是保护性修正，尚未进行逐关节因果替换，不能仅凭相关性指定责任手指。

## 固定每一条cmd，交换物理条件

额外回放完整存档cmd，绕过在线DP推理，只把物理条件从导入开始换掉。命令序列（包括静置和末目标保持）逐值核验相同。先在44g原条件重放其自身scale50命令，q、物体位姿和实际目标全程逐值复现原实验，再进行交换。

| 固定cmd来源 | 执行物理条件 | 第60步距竖直 | 最长连续竖直接触步数 | 首次分离控制步 |
|---|---|---:|---:|---:|
| 170g的scale50 | 170g/2.2，原存档 | 25.1° | 51 | 157 |
| 170g的scale50 | 44g/1.1，交换回放 | 43.1° | 2 | 170 |
| 44g的scale50 | 44g/1.1，自身重放 | 66.2° | 8 | 214 |
| 44g的scale50 | 170g/2.2，交换回放 | 19.7° | 20 | 74 |

**完全相同的cmd会产生明显不同的物体旋转，因此物理响应本身足以产生这类差异。** 44g命令在重物体上转得快，但很快分离，只有20步，仍未通过稳定翻转；不能将19.7°单帧当作救回成功。固定cmd干预也去除了后续闭环纠偏，不能把其保持表现当作新DP成功率。

见[replay_grasp_results.json](replay_grasp_results.json)，三个`replay_*`目录保存命令、逐步核验与完整轨迹；入口为[run_archived_command_diagnostic.py](../../run_archived_command_diagnostic.py)。

## 物理变化从哪里开始

1. **相同导入姿态≠相同动作起点。** episode54在170g/2.2与44g/1.1静置60步后，物体相差9.828mm和20.698°完整旋转，q相差RMSE0.01794rad。两组actor初始快照除质量、惯量和摩擦相关五个字段外相同；不是旧版PhysX覆盖root的初始化错误。本次同条件全程复现也支持这一点。质量干预同时改变了重力负载、惯量与静置后的接触构型，当前不能再把三者单独分解。
2. **摩擦有独立的动作阶段作用。** 44g/scale25只将摩擦1.1改为2.2，静置与前43步q、物体位姿、cmd相同。第44步手接触力、物体位姿和q开始出现微小差异，cmd仍相同；第45步cmd才发生差异。到第90步，物体角度29.46°与38.64°；第120步27.25°与35.63°。这条链支持“先改变接触动力学，再通过关节反馈改变策略输出”。第一处分叉非常小，不能把第44步直接称为宏观滑移事件，详见[friction_divergence_timeline.json](friction_divergence_timeline.json)。
3. **反馈并不直接观测翻转。** [policy_observation.py](../../../../../eval/policy_observation.py)的66维输入为`[q, previous_target, previous_target-q]`，取4帧历史；没有物体姿态、质量、摩擦、接触点或接触力。模型可以通过残差间接感知负载，但没有直接的物体角度闭环。guidance损失是归一化关节reference MSE，未直接优化物体竖直或接触力矩。高随机化训练不能把这个目标自动变成物体翻转目标。

由此，当前最有证据的解释是：**质量与摩擦改变静置平衡和后续接触迁移；scale改变偏离reference的关节组合；两者共同决定能否沿合适接触路径转正并保持。** 较大scale在重物体上有利，在轻物体上可能把动作推向不适合当前接触状态的路径。已有44g/1.1同插值direct也在episode54失败，而原速direct通过，说明连时间表本身都会改变接触结果；更贴某条reference不保证物体结果更好。

不能据此宣布“根因已精确到摩擦阻力矩过大/某根指头力不够”：日志主要是刚体净接触力，缺少物体—手指配对接触点、法向/切向分量、摩擦锥利用率和关节实际力矩。若继续细化，应先固定同一静置后完整仿真状态分离静置效应，再记录关键接触点/力矩并进行针对性的关节cmd替换；不是继续盲扫scale。

## 核验与范围

- 新增12次完整实际模拟：原条件guided复现1次；两种混合物理条件的原速direct2次与guide4次；direct补录视频2次；固定cmd重放/交换3次。没有改训练默认值、原生目标流、native failure规则或原reference；没有按guide结果换episode。
- 新增guide沿用DDIM4、guide2/exec1、>0.12插值，完整执行597动作步；direct执行462原始动作步。两者各另有60静置+60末尾保持。固定cmd回放为显式因果干预，不冒充在线策略评估。
- 原生协议显式保持：位置0.05m、各指尖0.1m、旋转180°、立即位置0.15m、FailureToleranceScale10000、fixedToleranceSteps20000、resetOnReachGoal=false、跨轨迹概率0.3、demo000–149；失败继续记录不自动重置。所有物理分离与稳定翻转指标只用于事后分析。
- 质量/摩擦设置后先simulate/fetch/刷新，再导入初态。新条件首控制步平移约8.55mm（170g）或11.21mm（44g），保存对应姿态变化；未出现旧版10–15cm跳回。
- 新混合条件同物理各组初态、静置状态逐值核验；跨物理仅指定属性变化。同条件复现的q、cmd、实际目标、object_pose、native_failure、hand_body_pose全程逐值相同。两段新direct视频均583帧，完整解码且逐步结果与无录像一致。见[validation.json](validation.json)与[runtime_reproduction.json](runtime_reproduction.json)。
- 本次是固定wrist手指回放诊断，不是完整真机放置复现。稳定翻转、保持到后面、握力更大是不同结论；本数据没有直接测量“握得更用力”。
