# Episode76 灯泡线性尺寸 ×1.1 诊断

源 frame114；固定 wrist；原始手 q、物体根位姿及固定静置目标完全不变。44g、摩擦1.1、30Hz、60步静置；没有运行 prior 或翻转动作。原生失败协议不变，两个实验60步均无 native failure。

通过在创建环境之前将 cfg.env.randomObjectScales 两端乘以1.1，保留 seed42 的同一个随机样本，actor scale 从0.987453997变为1.086199403。这是相对当前模型所有线性尺寸增大10%，绕原模型坐标原点缩放。质量仍44g；随尺寸变化的局部质心为原值×1.1，惯量为原值×1.21。27项初态中只有 object_scale/object_com/object_inertia 改变，其他字段逐值相同。

放大后中指更靠近，但零物理步及60步后仍有网格几何分离；物理运行时中指仍未记录到净接触力。单纯放大10%未解决中指贴合，且导入后的姿态变化增加。食指着色便于视觉比较，未对真机接缝位置做定量标定。真机相机外参未标定，不能用两视角截图直接确认真实接触或量取偏差。

## 排除的实现试验

最初在已经运行的环境上调用 set_actor_scale 再重写初态，首步出现约3.18m异常位移；结果判为无效，保存在 invalid_runtime_rescale，未用于本表。最终采用创建时缩放，按质量/摩擦设置→simulate/fetch/refresh→导入手与物体零速度的既有顺序运行。对应日志 scaled/sim.log；审计 comparison.json 与两组 geometry_audit.json。

没有写入 Downloads，默认实验尺寸仍为1倍。
