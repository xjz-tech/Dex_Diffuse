# 为什么摩擦1.4的表现可能变差

2026-09-27，事后对照既有trace/retention，无新仿真或参数变更。

## 已确认的轨迹差异

Episode54 原速reference两组发出的全部command逐值一致；60步静置结束的object位姿、实际手关节相同。初态快照只有hand_friction、object_friction变化。因而这条原速失败不能归因prior动作变化，也不是静置后换了抓握起点。

第40步，原有几何+净接触力指标在μ1.1时识别到拇指与无名指指腹；μ1.4时只识别到拇指指腹。第53步，μ1.4全部手link的记录净接触力均为0，μ1.1还有拇指/无名指/小指附近的接触证据。按原有3步连续几何分离判据，μ1.4首次分离原始进度54；μ1.1为118。注意净接触力不是pair-specific法向/切向力；这些记录不足以证明某根手指先黏住，或接触处确实经历了某种粘滑转换。

## 可支持的解释与边界

本次任务在手内改变物体姿态，需要动态接触位置与受力的协调。摩擦系数提高只改变给定法向力下可提供的切向摩擦范围，不保证实际抓握更稳；接触位置、法向力、运动和最终力矩也会随摩擦改变。原速reference本身不会依据灯泡真实接触结果修正后续关节目标。轨迹支持“摩擦改变了执行同一动作时的接触演化，使后续动作与物体状态失配”，但未独立识别准确的粘滑/滚动机制。

Guide还存在额外反馈途径：摩擦改变实际q与target residual，prior观察改变，后续生成动作也改变。guide中command的22关节RMSE首次超过两组间0.001rad差异的实际动作步为ep76第24步、ep34第15步、ep2第25步。因此guided对比包含物理和策略闭环响应，不能视作完全相同动作下的纯摩擦对照；raw/direct对此提供了控制。

这是固定seed与这些起点的结果，不能推广为摩擦越大一定越差。要确认具体机制，还需要物体—手指pair的接触点、接触法向/切向力与相对切向速度，或同一批生成动作的跨摩擦固定回放。
