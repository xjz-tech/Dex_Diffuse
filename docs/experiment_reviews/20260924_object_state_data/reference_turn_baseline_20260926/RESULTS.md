## 核验与限制

每episode三组27项初态逐值相同，60步静置的位姿/关节/指令/手接触记录逐值一致，物体净接触力归约差异<1e-5N。源state/actions逐值核验，guide调用索引按实际exec滑动；全部reference尾段及60步hold执行完，没有按失败停止或重置。原生xjz_test.sh协议和全部阈值保留。

现在证明的是这4个具体仿真起点的**原始动作可完成近竖直翻转**。TCP→手根、动捕→网格外参仍未独立标定，没有据此宣称完整初始化映射已经校准，也未修好旧50/70/40的所有可能起点。固定wrist且无插座，不代表完成真机放置。
