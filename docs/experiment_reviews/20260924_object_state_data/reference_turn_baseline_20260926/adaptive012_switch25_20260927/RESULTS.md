# 0.12 rad 选择性插值；灯泡接近竖直后 scale 50→25

四条 episode 都从各自已抓住灯泡的横抓初态开始，且已经通过未经修改的原速 reference 稳定翻转验收；本组结论仅适用于这个条件子集。相邻 reference actions 的 22 关节最大绝对跳变严格大于 0.12 rad 时插入一个中点。使用 10B EMA、DDIM4、guide 2 / exec 1、固定噪声 44、环境 seed 42、固定 wrist、灯泡 170 g、摩擦 2.2、30 Hz。原生 failure 参数沿用 `eval/xjz_test.sh` 协议，运行完整动作尾段及额外 60 步 hold；没有录制新视频。

本次新组在**实际仿真灯泡局部 +Y 长轴首次距世界竖直不超过 30°**的控制步结束后，从下一次 prior 预测开始，把 guidance scale 从 50 改成 25，随后保持 25；每次仍只执行生成动作的第一步。30°沿用这四条原始 direct 翻转验收的角度阈值。prior 预测日志逐次记录了实际 scale，切换不是按预设 reference 步号进行。
