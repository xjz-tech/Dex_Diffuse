# Episode 76：静置固定目标 A/B

使用 episode76/state114 的自身手关节和 object-in-wrist 初态，44 g、手与灯泡摩擦 1.1、环境 seed42、固定 wrist、30 Hz、60 个控制步。此次只有静置阶段，不运行 prior、不推进 reference、不录制视频。A 的固定目标为初始实测手关节角，B 的固定目标为 action.npy[114,9:]；两者均按原仿真关节限位裁剪，并在导入后全程保持目标不变。

两组仍沿用原生环境评估协议及失败逻辑。除 target 和由 target 计算的 observation 外，全部初态字段精确一致；A 与先前同物理参数回放的 60 步关节、指令、物体位姿和 native failure 逐值一致。B 唯一修改实验变量是固定的目标角。两组均执行满 60 步、原生 failure 均未触发；独立网格近接触与受力检查在末 30 步均保留至少三个近接触链接。这些静置指标不是翻转成功率。

**固定首个 action 目标没有改善初态保持，反而增加了灯泡和手指相对源状态的偏移。** 这不支持将“q_target=q_initial 导致预紧力丢失”作为已经确认的主要原因，也不支持直接用首个 action 替换静置目标作为修复。原始 action 位于动态翻转轨迹中，可能包含主动转动意图，并不是经过独立确认的静态抓握力平衡目标；本实验只能判断这项具体改动的效果，不能排除预紧力有影响。真实软接触与仿真碰撞几何、TCP/手根及物体网格外参、关节控制参数的匹配仍待进一步验证。

两组宏观位姿变化主要集中于前段，末段没有持续显著漂移。但记录的 PhysX root velocity 与相邻控制采样的位姿差分速度不一致：A 末 30 步线速度模中位数分别为 0.2637 m/s 与 0.000936 m/s，B 为 0.0788 m/s 与 0.0000480 m/s；角速度也存在差别。这可能涉及接触求解器或采样时刻，尚未独立查明。不能把 root velocity 数值直接换算为持续滑移，也不能仅根据宏观位姿小变化就断言严格静态平衡。
