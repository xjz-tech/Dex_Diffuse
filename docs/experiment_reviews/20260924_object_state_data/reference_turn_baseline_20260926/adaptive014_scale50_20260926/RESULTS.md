# Scale 50、guide 2 / exec 1：0.14 rad 选择性插值

四条 episode 均从各自已经抓好灯泡的原始初态开始。只有相邻两个原始 reference action 的 22 个关节中，最大跳变严格大于 0.14 rad 时，才在两者之间插入一个线性中点。使用 10B EMA、DDIM 4、guide 2、scale 50、exec 1；灯泡 170 g、摩擦 2.2、固定 wrist。所有回放均执行完整 reference 尾段及额外 60 步 hold，未录视频。

0.14 guide 相对 0.12 guide：episode 76 早 11 个原始动作、34 持平、54 早 3 个、2 晚 13 个；四条平均进度从 139.5 变成 139.25，几乎没有整体改善。相对原速 reference direct，0.14 guide 只在 episode 34 延长了分离前进度。0.14 direct 对照在 episode 54 很早分离，说明改变插值规则本身显著影响动力学轨迹；这四条固定种子的结果不足以把差异归结为 prior 动作质量的一般规律。

本组新增结果的初态文件全部字段与各自原速 direct 完全相同；60 步静置轨迹除物体接触力浮点归约误差外逐字段相同，误差不超过 `3.82e-6 N`。已核对展开后的 reference、预测窗口索引、原生 failure 协议和完整尾段。将分离判据的近距离阈值由 5 mm 改为 3/8/10 mm，首次分离进度最多改变 1 个原始动作。几何/接触分离是独立分析指标，不等同于原生环境 failure，也没有视频独立确认。
