选择性插值四条合计比全插值少 **1181 个中点（72.5%）**；完整尾段的控制步数少 **1181/3264 = 36.2%**。首次分离前实际执行步数的差异也见上表，例如 episode 54 的 guide/exec1 从全插值的 110 步变成选择性的 157 步，且对应原始进度从 55.5 延后到 125。

表中脱手进度是首次连续三个控制步满足独立几何/接触分离判据时，对应的**原始 reference 动作进度**（1 起；`.5` 为插值中点），并非新增控制步数或原生 native failure。括号内的“通过”要求物体距竖直不超过 30°、离桌超过 8 cm、至少两个手部 link 在 8 mm 内且各有超过 0.05 N 的接触力、物体合力超过 0.1 N，连续至少 30 控制步并发生在首次分离前。对 episode 34 和 54 的选择性 guide/exec2，虽然到进度 189/188 才分离，但最长连续竖直接触只有 10/12 步，**不能算翻转成功**。episode 2 的选择性 guide/exec1 恰好只保持了 32 步，也仅略过验收阈值。

因此这个 0.12 rad 选择性规则**对 exec1 有帮助，但不稳定地改善保持；对 exec2 反而降低翻转通过数**。仅用平均脱手进度会得出相反印象，因为 exec2 的 34/54 可以保持较久，却没有持续完成竖直接触。新组的选择性 direct 对照 4/4 能通过翻转，说明选择性插值本身并未使这四条基线失去翻转能力；guide/exec2 的失败来自同一时间表下生成动作与物理轨迹的变化。这个因果比较限于这四条和固定 seed，不等于一般成功率。

核验：四条各自的 source `action.npy` 经阈值规则展开后，在模拟器和 guide server 中使用同一算法；每一条原始目标的值与顺序均保留。12 个新增结果的初态文件全部字段与该 case 原始 direct 相同，60 步静置轨迹除物体接触力浮点归约误差外逐字段相同（差 < `1e-5 N`）。预测窗口索引按实际 exec1/2 递进；仿真跑完整尾段和末尾 60 步；原生 failure 协议不变。几何分离阈值在 3/5/8/10 mm 间变化时，脱手进度最多变化 1 个原始动作。新增结果没有视频独立确认，物理分离仍是碰撞网格距离与接触力分析标记。
