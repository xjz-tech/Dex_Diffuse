# Scale 50、guide 2 / exec 1：相邻关节跳变严格大于 0.09 rad 才插入一个中点

使用同四个已通过原始 reference 翻转验收的横抓起点：episode 76/f114、34/f79、54/f110、2/f103。每对原始动作计算 22 个关节中最大的绝对变化，严格大于 0.09 rad 时插入一个线性中点；所有原始目标保留。新增四条选择性插值 direct 与四条 10B EMA/DDIM4、guide2、scale50、exec1 的完整仿真。质量 170 g、摩擦 2.2、原生固定 wrist、环境 seed42、prior 固定噪声44、30 Hz、60 步静置、完整动作尾段和末尾60步 hold沿用前轮。未录新视频。本报告不比较其他执行步数。

## 核验与限度

8个新增结果的初态文件全部字段与各 case 原始 direct 完全一致；60步静置除物体接触力浮点归约误差外逐字段相同（最大差<`1e-5 N`）。阈值在模拟器与 prior server 中均用存储的 float32 原始目标转换到 float64 后比较，保证严格 `>0.09` 在不同 NumPy 版本下一致；全部进度映射逐项验证。direct 发出的命令与选择性插值目标一致；guided 每次预测的reference索引按 exec1 实际执行步递进。原生 failure 协议不变，完整尾段与60步hold均已执行。几何分离阈值在3/5/8/10mm变化时，首次分离的原始进度最多变化1个动作。

曾发现 NumPy 1.x 与2.x 对接近0.09的float32差值作标量比较时行为不同。早期不同步的部分运行已移至 `discarded_before_float64_fix/` 并排除；仅源进度表与修正算法逐项一致的 episode76/34 direct 记录被复用，其余受影响运行重新执行。该问题及修复记录在目录内。新增结果无视频独立确认；几何/接触分离是分析标记，不代替原生 failure 或完整真机抓握结论。

可复现入口：`../../run_turn_adaptive.py 0.09` 与 `../../analyze_turn_adaptive.py 0.09`。逐条数据见 `RESULTS.json` 和各 case 的 `direct_adaptive009/`、`guide1_adaptive009/`。
