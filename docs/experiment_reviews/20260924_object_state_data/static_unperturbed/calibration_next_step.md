# 真机抓握复现的缺失标定

当前已能核对 `state.npy` 中的手关节顺序，按行读取 TCP 旋转，并按原生仿真 wrist 导入位姿。但源 episode 没有附带以下两个固定变换：

1. `T_TCP_handroot`：Franka 返回的 TCP 坐标到 SharpA 仿真手根坐标。需要采集时的工具坐标设置、机械臂末端到手根的测量或同一静止姿态的标定。
2. `T_marker_bulbmesh`：`obj_state.npy` 所表示的物体跟踪坐标到 `bulb1_col.obj` 网格坐标。需要动捕刚体/标记点标定和灯泡实际外覆层尺寸。

正确导入应使用

`T_handroot_bulbmesh = inverse(T_base_TCP @ T_TCP_handroot) @ T_base_marker @ T_marker_bulbmesh`。

旧实验把两个未知变换都当成单位矩阵，还在运行中的 GPU 仿真内修改质量后立即写入位姿；该设置顺序导致写入值未成为实际物理初态。修正为“修改质量/摩擦→推进并同步一帧→写入初态”后，无扰动 episode51/53 第一步相对位移为 0.59/2.41 cm、末步为 1.46/2.78 cm；均未触发原生 failure，但仍有 1.47–3.23 cm 的离线网格互穿。沿 wrist X 移 −4 cm 仅改善 episode53 的平移稳定性，旋转仍超标，也不能作为标定。

拿到标定后，应先在 episode51 第105帧、episode53 第90帧及其后续帧上独立检查手/物体轮廓和碰撞，再用相同的 170 g、摩擦 2.2、原生 wrist 和原生 failure 配置重复 60 步静置，并先完成物理属性更新再写初态。预先采用以下进入策略比较的门槛：两段起点无厘米级网格互穿，第一物理步相对位移 < 5 mm，60 步末相对位移 < 1 cm、旋转 < 10°，且没有原生 failure。当前修正后的两段都未满足。若没有满足，继续校正标定/模型，不运行原始动作与 10B prior 的真实复现比较。上述阈值是本诊断为物理初态设置的额外验收门槛，不改变原生环境 failure 判定。
