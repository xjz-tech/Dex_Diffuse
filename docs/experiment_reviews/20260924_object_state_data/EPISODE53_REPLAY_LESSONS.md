# Episode 53 灯泡复现经验：哪些成功可保留，哪些坑不能重踩

2026-09-26。依据存档脚本、初态快照、逐步轨迹和视频回查；不是凭聊天印象重建。

## 先区分两次“成功”

- **旧 case467 / comparison slow**：episode53，state90，action90–164，170g、摩擦2.2。导入时还申请了 wrist 局部 `[+2,+2,-2]` cm 和物体局部 X 轴15°扰动。视频里确实有同一实际初态下 direct 脱手、prior 保持并转动的差异；结束还有3个指尖接触、灯泡离桌约12.38cm。但后续发现 PhysX 初态写入顺序错误，实际开始状态不是申请的源数据位姿。它支持当时那一个仿真状态下的成对策略对比，不能证明真实抓握被正确迁移。
- **修正初始化后的 episode53**：state90，完整动作90–446，state447作为终点；原生固定 wrist。direct 执行357个原始目标；10B EMA/DDIM4、scale50、guide2，在原始相邻目标间插1个中点，exec1或exec2，均执行713个目标。两种执行步长各自按实际执行数前进 reference。完整记录见 `corrected_direct_vs_reference/full_episode53/README.md`。该版三组27项初态和60步静置轨迹逐值一致。

后一版报告的 direct action216/source306 和 guided action603/source391–392 是 **native failure 的零起始索引**，不能直接改名“物理脱手步”。当前实验另外保存手几何与接触证据，以原始动作进度比较保持能力。

## 当前四条实验的固定约定

按初始几何筛选、固定随机种子打乱episode顺序、只静置检查，通过后取前4条，**不根据direct/guide保持结果挑例子**。起点的姿态与接触需录像复核；筛选失败也保留原因。参考为修正版ep53，不恢复case467错误的初始化。

质量0.17kg、手与灯泡滑动摩擦2.2，原生固定wrist与随机化，环境seed42、prior固定噪声44；10B EMA，DDIM4、guide2、scale50、插1中点。同时保留exec1与exec2以对应ep53完整三组对照。原始direct不插值；因此当前对比衡量**整套guide+放慢方案**，不能孤立归因prior（若要因果分离，需增加插值direct组）。

## 用户复核后的必要补充：静置抓稳不等于翻转初态合格

上一轮50/76/70/40只验收静置，错误地将它们作为合格翻转对照。direct在脱手前分别未到30°、只到30°内5步、1步、8步，均未稳定完成横转竖。原脱手时刻可以保留，但不能解释为有效翻转任务的guide改善。

后续按用户新要求增加功能基线：每条使用自身仍横抓的源状态，未经修改的原始reference以原30Hz直接执行；必须达到距竖直30°内并连续至少30步仍悬空握住，通过接触/几何/录像检查，才进入guide对照。允许在同episode真实横抓段重新选帧；不悄悄调质量、摩擦、动作速度、物体偏移来制造通过。若必须换episode，记录筛选路径，并明确结果只适用于direct可完成翻转的条件子集。guide的输赢不得参与筛选。

### 功能验收的实证

ep76从state94改为自己的state114，并同步把reference切到action114开始后，在同样170g/摩擦2.2/固定wrist/30Hz原始动作下，可以从约71°横抓转到近竖直并连续保持125控制步。原state94版本只短暂到竖直就掉。两起点的手q相差RMSE0.3054rad，object-in-wrist位置差1.58cm、旋转差23.34°。静置稳定并没有验证这种接触构型能承受后续翻转。

新基线为76/f114、34/f79、54/f110、2/f103；每条direct均通过≤30°、至少30连续控制步仍悬空接触的验收。前三十步几何接触单独核验，完整竖直接触段为125/125/99/112步。旧50/70/40在本轮已测起点未通过，不能声称已修好这些episode，替换和条件筛选在 `reference_turn_baseline_20260926/RESULTS.md` 逐项记录。指导原则：先证明direct能完成翻转，再讨论guide相对收益；guide的持有时长与完成翻转应分别报告。

### 2026-09-27：静置目标与抓握预紧力的单变量诊断

ep76/f114、44g/摩擦1.1 下，将静置固定目标从初始实测 q 改为该帧原始 action，其他初态不变，60步后的灯泡偏移从6.48mm/7.82°增加到10.67mm/13.83°，关节相对源 q 的RMSE从0.0301增至0.0640rad。没有证据把“卸掉预紧力”认定为初始化偏移的主要原因；原始action可能包含主动运动意图，不能直接当作静态平衡目标。两组末30步位姿变化均很小，但root velocity与控制帧位姿差分不一致，不据此宣称持续滑移或严格静态平衡。完整数据见 `reference_turn_baseline_20260926/episode76_settle_target_ab_20260927/RESULTS.md`。主实验的默认静置目标保持不变。

### 2026-09-27：零物理步中指与 RL 坐标核验

ep76/f114 的精确FK重建证明，中指指腹零物理步就与灯泡碰撞网格分离至少13.573mm，首控制步后为11.202mm；不是静置使中指从原接触位置脱开。FK与记录的33个手刚体位置最大误差<1.4e-7m。真实数据与导入状态用原生RL `calculate_relative_pose` 计算的相对位置差3.22e-8m、旋转差1.52e-6°；手根固定变换已包含、现有真机读取代码的policy关节顺序一致。没有发现导入相对RL坐标约定的漏乘变换，不能擅自追加TCP补偿。actor随机缩放恢复到1最多改变表面0.859mm，无法消除该中指间隙。完整结果及零步图见 `reference_turn_baseline_20260926/episode76_zero_step_audit_20260927/RESULTS.md`。原始direct通过翻转只证明具体仿真初态可用，不证明逐指接触等同真机；应分别验收。

### 2026-09-27：质量、摩擦与scale的因果诊断

同口径>0.12插值、DDIM4、guide2/exec1的四条存档，170g/2.2的scale25是3/4稳定翻转，44g/1.1是4/4；不能与>0.10插值版本或早期未修正起点混称0/4→4/4。对优劣互换的ep54/f110补齐质量×摩擦对照（新条件均先通过原始direct验收），最长连续竖直接触步数：170g/2.2为scale25/50=11/51，170g/1.1为4/36，44g/2.2为7/0，44g/1.1为42/8。≥30步为通过；此结论限该起点/seed，不推广为普遍成功率。

scale50前60步cmd-reference误差约为scale25的一半，但轻物体翻转更差；没有显著限幅，±10步对齐的最佳cmd偏移为0。固定整条cmd交换物理条件仍使转动明显改变，证实不能只归因在线cmd生成。原条件复现与自身cmd重放均逐值核验。跨质量静置后的完整姿态已相差20.7°；44g只改摩擦时静置和前43动作步相同，第44步接触/状态先分叉，第45步cmd才不同。接触路径与引导手型的交互有实验支持，但尚不能凭净接触力确定某个接触点的法向/切向力矩。详细命令、12次新增模拟、录像与限制见[诊断报告](reference_turn_baseline_20260926/mass_scale_diagnostic_20260927/REPORT.md)。
