# 初始化手型与质量分组保持率

成功口径：仿真400秒仍未触发原生failure。基线为历史guided-DDIM scale0，不等于普通DDIM。

## 实际初始化静态重建

用恢复记录的关节角、物体相对腕部位姿、物体缩放和原始URDF渲染。为便于比较，把所有手腕统一到同一朝向，保留手—物相对姿态；没有推进物理仿真，不是原始录像。每列同demo、上排快失败、下排基线到400秒。展示的是案例，不是平均手型。
