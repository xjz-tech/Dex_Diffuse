# 真机初始手型：1B + 10k guide 对照

每组16轮，使用上一轮归档的4组实测手型与仿真灯泡摆放，各分配4个扩散采样seed（50–65）。三组逐项相同的关节角、腕部和灯泡初态，复用逐chunk的1B高斯噪声；guide另用seed+100000。

配置：DDIM4/4，30Hz，执行2步，引导前2步，scale25，不holding，无额外推理等待、随机外力或域随机化；沿用物理关节范围，无单步限幅。首次灯泡中心相对初始位置偏移>5cm视为脱离初始抓持区域，最长400秒。它不是旋转任务成功率。
