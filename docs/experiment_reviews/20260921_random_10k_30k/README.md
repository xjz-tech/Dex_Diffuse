# 原始采集库随机重训10k与30k

2026-09-21。目的：固定普通1B，检验重新随机选取训练轨迹后，guidance能否重现旧10k的改善方向和幅度。

事先固定：从旧10k相同的 `/home/carus/Data/exp_data` 源库，使用相同完整轨迹抽样器，10k抽样seed43，30k抽样seed44。两份独立抽样，均不按闭环结果挑选数据。训练seed42、episode验证划分seed42、200 epochs及其他模型/优化器参数沿用旧10k，从头训练并使用EMA。30k每epoch更新更多，故这是“相同epoch训练配方”的复现，不能把差异完全归因于数据量。normalizer沿用全子集拟合，包括验证行。

此设计复用原采集库，而非重新采集；原库缺失实际mass/friction标签，不能恢复或伪造每个新子集的实际质量/摩擦比重。保存源episode/env/length、示范覆盖及训练窗口权重。

评估复用20260920_10k_domain_guides的48个配对case：4初始化×4物理格点×3推理噪声seed，400s上限。沿用原生xjz_test失败口径、DDIM4/4、exec2、scale25、引导前2个执行动作。普通1B/旧10k使用上一轮已完成的48-case参照，须验证新运行的初态、物理参数与参照完全一致。不运行scale0。原生failure仅为失败代理。

上轮重复运行曾观察到相同初态/首动作但后期保持时间有变化；本次每种新数据集仅训练一个模型、每case运行一次。因此可检验这两份新数据上的改善，不能据此宣称普遍或精确秒数可复现。单case小差异谨慎解释。
