# 剔除每种方法最好和最差的 prior 噪声 seed

基于同一批 10 个随机噪声 seed 的 720 条审计轨迹。每个 seed 在一种方法下含 3 个 prior × 4 个 episode × 3 组物理参数，共 36 条。按**稳定翻转数**排序；若相同，用首次几何分离前的平均实际控制步数打破平局。对 guidance 和 replay edit 分别剔除一个最差、一个最好 seed。每种方法内三个 prior 保留**相同的 8 个 seed**，因此仍可配对比较。

| 方法 | 剔除的最差 seed | 剔除的最好 seed | 排名依据 |
|---|---:|---:|---|
| guidance | 234124 | 748482 | 稳定翻转 15/36、24/36 |
| replay edit | 234124 | 486266 | 稳定翻转 18/36、28/36；最差与 671925 同为 18/36，以平均步数打破平局 |

| prior | 方法 | 普通翻转 | 稳定翻转 ≥30 步 | 平均执行步数 |
|---|---|---:|---:|---:|
| 旧 1B | guidance | 76/96 | 52/96 | 188.1 |
| 10B | guidance | 73/96 | 45/96 | 193.0 |
| h8 | guidance | **90/96** | **58/96** | **210.2** |
| 旧 1B | replay edit | 82/96 | **66/96** | 192.6 |
| 10B | replay edit | 81/96 | 52/96 | 175.7 |
| h8 | replay edit | **90/96** | 61/96 | **200.5** |

作为敏感性检查，如果**每个 prior × 方法单独**剔除各自最好和最差的 seed，稳定翻转数分别为：guidance 旧 1B 53/96、10B 48/96、h8 58/96；replay edit 旧 1B 67/96、10B 53/96、h8 58/96。排序不变；但此做法各模型保留的 seed 不同，不作为主比较。

若改用**平均执行步数**定义 seed 的好坏，guidance 剔除 671925、662165；replay edit 剔除 234124、323567。稳定翻转排序依然不变：guidance 为 h8 56/96、旧 1B 53/96、10B 46/96；replay edit 为旧 1B 67/96、h8 64/96、10B 55/96。

普通翻转指分离前至少一个控制步达到竖直、悬空且有效接触；稳定翻转要求连续 ≥30 步。平均执行步数从动作开始计至首次连续 3 步几何分离。10 个 seed 仅改变 prior 采样噪声，环境初态仍是固定的 4 个 episode × 3 组物理条件；这不是 96 个独立抓握初态。原始逐条结果见 [audited_results.json](audited_results.json)。
