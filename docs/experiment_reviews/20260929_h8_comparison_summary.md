# h8 与旧 1B、10B：自主转动及 reference 编辑对照

## 3000 个相同随机初态上的纯 prior

seed42、示范 000–149、EMA、DDIM4、exec2、无外力；每条首轮最多观察 900 控制步。三组初态的 27 类字段逐值一致。旧 10B 复用同协议完整记录；旧 1B 的历史长时实验使用了不同外力和环境数量，因此本轮按相同协议补跑。完整来源及统计见 [3000 环境报告](20260929_h8_prior3000/REPORT.md)。

| 模型 | 900 步时未触发原生 failure | 前 150 步失败 | 截断平均步数 | 净右转 >30° |
|---|---:|---:|---:|---:|
| 旧 1B | 2031/3000 | 358/3000 | 716.4 | 314/3000 |
| 10B | 2045/3000 | 348/3000 | 716.9 | 342/3000 |
| h8 | 2083/3000 | 373/3000 | 714.6 | 228/3000 |

h8 到 30 秒仍未失败的比例略高，但前 150 步失败更多，截断平均步数没有提高，自主净右转的比例反而最低。因此不能把它描述为更擅长自发右转。900 步上限将约三分之二的轨迹截尾；原生 failure 是任务判据，不能直接解释为视觉确认的物理掉落。

## 四个横抓起点的 reference guidance / replay edit

四个 episode（76、34、54、2）各使用自己的合格横抓初态，跨 44g/摩擦1.1、170g/2.0、130g/2.4 三组物理参数，prior 噪声 seed44、45、46。共 12 种 episode×物理条件，每种重复三个 seed。所有模型使用 DDIM4、exec2、相邻 reference 的 22 关节最大跳变严格 >0.1rad 时插入一个中点。Guidance 为 scale50、guide4；edit 为噪声0.15的局部四步去噪。完整条件、逐物理参数和逐 seed 表见 [回放实验报告](20260929_h8_object_state_data/REPORT.md)。

| 模型 | 方法 | 普通翻转 | 连续≥30步稳定翻转 | 平均观察动作步数* |
|---|---|---:|---:|---:|
| 旧 1B | guidance | 32/36 | 28/36 | 195.8 |
| 旧 1B | replay edit | 34/36 | 27/36 | 198.7 |
| 10B | guidance | 34/36 | 22/36 | 194.2 |
| 10B | replay edit | 33/36 | 22/36 | 166.7 |
| h8 | guidance | 35/36 | **30/36** | **224.7** |
| h8 | replay edit | **36/36** | 29/36 | 207.2 |

*从动作起点至首次连续三步几何分离；完整 reference 尾段仍未分离者在尾段截尾。该指标基于接触和几何审计，独立于原生 failure。216 条轨迹的导入初态和 60 步静置轨迹都与对应 direct 对照一致，没有缺失或重复 case。

h8 在这批固定起点中整体最好：guidance 的稳定成功数和观察步数最高，edit 的普通翻转达到 36/36。与旧 1B 相比，h8 的稳定成功数在两种方法下都只多 2/36，幅度较小。h8 自身也不是 edit 全面胜过 guidance：edit 普通翻转多 1 条，但稳定成功少 1 条、平均观察步数少 17.5 步。

随机性尤其值得注意。h8 guidance 三个 seed 的稳定翻转为 12/12、7/12、11/12；h8 edit 为 12/12、10/12、7/12。10B edit 从 seed44 的 11/12、seed45 的 10/12 降到 seed46 的 1/12。seed45/46 的 10B edit 使用相同 checkpoint、EMA、噪声比率、DDIM 时刻、物理参数和初态，采样 seed 不同。将 seed46、170g/2.0、episode76 的 edit 单独重跑，summary 完全一致，执行命令、关节状态和物体位姿逐步一致，首次几何分离同为动作第9步；因此这不是并行运行造成的随机坏点。单次 seed44 的优异结果不能代表稳定表现。

综合看，h8 更能在给定 reference 的情况下完成并维持这四类横抓翻转，但纯 prior 的自主右转比例并未提高。这提示它的强项更可能是沿 reference 附近维持抓握与接触，而不是自发选择正确右转方向；这是一项根据两类实验作出的推断，不能单独归因于模型大小。h8 的预测窗口为未来5步，旧 1B/10B 为未来9步，跨 checkpoint 比较也包含窗口差异。
