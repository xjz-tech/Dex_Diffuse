# 最短一轮：seed 65

本组16轮由4组初态各分配4个不同扩散采样seed组成，是探索性对照。4组手型取同一ROTATE目标下4轮真机实测值，各自匹配经静态检查的仿真灯泡摆放；每组内部初始qpos和物体位姿逐项完全一致。所有轮次均不holding；来源名称中的hold只标识历史日志。

最短一轮为real_bulb组trial=15（从0计）、全局env=47、seed=65。第22个控制周期末（索引21，0.7333秒），灯泡中心相对初始位置偏移5.0859厘米，首次超过5厘米诊断阈值。相同初态的静态保持1秒检查中，中心偏移1.0684厘米。

0.6秒时灯泡中心横向已经偏移约2.74厘米，而竖直下移约0.61厘米；0.733秒时竖直下移约4.02厘米。保存状态显示先横向移动并转动，再下落。日志没有每根手指的接触状态，不能把失稳归因于某一根手指。前22步的平均最大关节目标差0.08350rad、最大0.11318rad，并非同初态四个seed中幅度最大的那轮。

这16轮没有同步录制视频。replay_025x.mp4是根据保存的关节角和物体位姿重建的双视角状态回放，0.25倍速，首尾各停留1秒。不是原实验现场录屏，也不是重新运行策略。每帧恢复保存状态后，在关闭重力、接触与速度的渲染环境中前进1微秒以刷新GPU变换；姿态偏差经过逐帧断言，数值见metrics.json。视频标签和失效判定使用原始保存数据。

同初态不同seed的差异说明采样动作序列会影响结果；当前没有固定seed的重复试验来单独量化物理数值非确定性，也没有完整交叉所有姿态×相同seed，不能把所有时长差异严格归因于seed。
