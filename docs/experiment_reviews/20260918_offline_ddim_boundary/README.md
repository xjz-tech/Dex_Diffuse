# 离线训练窗口：DDIM 步数与 0.09 边界

日期：2026-09-18。未推进仿真。从 10k 训练 zarr 取完整 4 帧观测，输入 `obs_4-66.ckpt` EMA。同一批窗口、同一份初始噪声，对比 DDIM 4/8/16/32。

## 协议

- 数据：`data/sim_hand_10k_seed42/replay_buffer.zarr`，训练划分 18 条 episode（`val_ratio=0.1, seed=42` 去掉 2 条），无 padding 的完整窗口 **8712** 个。
- 观测：每窗 `obs[0:4]`，形状 `(4, 66)`。上一目标 `o_t[22:44] = obs[3, 22:44]`。
- 时间对齐：`action_start = n_obs_steps - 1 = 3`。首个待执行动作是 `action_pred[:, 3]`，不是第 0 帧。可用 chunk 为 `a[t:t+9]`。
- 证明没用第 0 帧：DDIM4 下 `||action_pred[:,0] − â_t||_∞` 均值 0.230 rad。
- 噪声：一次抽好 `(8712, 12, 22)`，`noise_seed=42`，四个步数复用。
- Scheduler：由训练 DDPM 配置转 DDIM（`num_train_timesteps=100`，`squaredcos_cap_v2`，`clip_sample=true`，`prediction_type=epsilon`，`timestep_spacing=leading`）。Normalizer 来自 checkpoint，未重拟合。
- 超限：`> 0.09 + 1e-6` rad。

$$
d_{\mathrm{first}}=\|\hat a_t-o_t[22:44]\|_\infty,\qquad
d_{\mathrm{inside},k}=\|\hat a_{t+k}-\hat a_{t+k-1}\|_\infty
$$

`d_inside` 把 k=1…8 全部摊开（8712×8=69696）。

原始数：`statistics.json`、`deltas.npz`。脚本：`run.py`。

## 结果

| | `d_first` 超限 | `d_first` 均值 / 中位 / max | `d_inside` 超限 | `d_inside` 均值 / 中位 / max |
|---|---:|---|---:|---|
| 训练标签 | 0 / 8712（0%） | 0.0802 / 0.0900 / 0.0900 | 0 / 69696（0%） | 0.0800 / 0.0900 / 0.0900 |
| DDIM4 | 5668 / 8712（**65.06%**） | 0.0850 / 0.0926 / 0.1415 | 41298 / 69696（**59.25%**） | 0.0835 / 0.0918 / 0.1520 |
| DDIM8 | 5735 / 8712（65.83%） | 0.0845 / 0.0927 / 0.1387 | 43534 / 69696（62.46%） | 0.0836 / 0.0925 / 0.1593 |
| DDIM16 | 5758 / 8712（66.09%） | 0.0843 / 0.0927 / 0.1381 | 44108 / 69696（63.29%） | 0.0835 / 0.0927 / 0.1606 |
| DDIM32 | 5778 / 8712（66.32%） | 0.0843 / 0.0928 / 0.1386 | 44385 / 69696（63.68%） | 0.0835 / 0.0928 / 0.1652 |

DDIM4 的 chunk 内逐步超限：k=1…8 分别为 65.09%、63.64%、62.65%、60.84%、58.86%、56.30%、54.58%、52.08%。没有“只有衔接点超、内部正常”。

## 对照排查表

| 观察到的结果 | 这次测到了吗 | 排查方向 |
|---|---|---|
| 真实训练窗口输入下，DDIM4 已经大量超限 | 是。首动作 65.06%，chunk 内 59.25% | 不需要闭环状态漂移，现象就能出现；优先检查模型、采样及输入输出处理 |
| 增加 DDIM 步数后明显改善 | 否。4→32 超限率略升，不是下降 | 不支持“少步采样误差是贡献因素” |
| 离线输入下基本不超限，闭环才明显超限 | 否。离线已经大量超限 | 不优先查在线观测构造 |
| 首动作差明显异常，chunk 内部较正常 | 否。两者同量级 | 不能只查上一目标锚定 |
| chunk 内部也明显超限 | 是。8 个相邻对都过半超限 | 不能只归咎于新旧 chunk 衔接 |
