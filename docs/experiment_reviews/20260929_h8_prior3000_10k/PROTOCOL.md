# 3000 个配对初态，10000 控制步纯 prior 长时对照

沿用 `20260929_h8_prior3000` 的 seed42、示范 000–149、3000 个配对随机初态、EMA、DDIM4、每次执行2步、零外力与原生 `eval/xjz_test.sh` 失败判定。本次只将首轮轨迹观察上限从900改为10000控制步；到上限仍未失败的轨迹标记为右删失。三个 checkpoint 依次串行运行，防止相互争用 GPU。每次运行写入独立目录与完整原生日志；`analyze.py` 逐字段核对新初态与之前的900步初态，并生成10000步截断平均时间。

显式参数：物体位置误差0.05m、指尖误差0.1m、物体旋转180°、立即失效位置误差0.15m、`FailureToleranceScale=10000`、`fixedToleranceSteps=20000`、`resetOnReachGoal=false`、跨轨迹目标概率0.3。原生任务的 `trajStepsLimit=12000` 保持原样；10000是本次观察上限，不是任务目标更新阈值。原生 failure 仅作为评估失败代理，不等同于独立确认物理掉落。

`RUN_COMPLETE` 只在对应模型完成并通过初态、步数、零外力与 episode 记录核验后写入。批次完成时生成 `comparison.json`。平均时间按 `min(原生失败时间, 10000)/30` 计算，是333.3秒内的截断平均，不是无上限的失效时间期望。
